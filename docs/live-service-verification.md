## 重复检查

从 `backend/` 执行：

```powershell
.\.venv\Scripts\python.exe scripts/verify_live_services.py
# 额外检查有密钥但未参与当前主备路由的文字服务：
.\.venv\Scripts\python.exe scripts/verify_live_services.py --include-standby
```

工具读取当前进程及 `.env` 配置，优先级与应用一致。会产生少量模型用量，
仅向模型发送固定合成文本；不输出密钥、连接串、原始异常、模型回复或知识正文。
数据库强制只读，不启动应用生命周期或调度器，不发送邮件或企业微信消息。
补充：配置 ClamAV 地址后，会额外发送固定干净数据流检查连接；默认不发送病毒测试签名。
扫描接入及独立验证工具见[业务通知与附件扫描接入](notification-scanner-integration.md)。
模型响应上限 128 tokens、请求预算 30 秒，嵌入和 SMTP 沿用应用的有界超时。
配置不完整或探测失败输出安全错误码，不输出供应商响应详情。

`PASS` 为该检查范围通过；`MOCK` 为模拟服务；`DISABLED` 为未启用；
`UNVERIFIED` 为未完成实际验证。退出码 1 表示存在 `FAIL` 或检查无法完成；
退出码 0 只代表没有失败探测，可能仍有未验证或禁用项，不代表生产就绪。
报告固定保留 `production_acceptance=false`。
