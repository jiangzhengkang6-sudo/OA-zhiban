## 版本 A：简历标准版（分点式，适合"项目经验"栏）

**OA 智能体管理系统**（个人独立开发） 【2026.xx – 至今】

**项目描述**：面向中小企业办公场景，独立设计并开发"OA 本体 + AI 智能体编排"一体化系统。智能体承接申请预检、制度问答、内容起草、催办编排等重复性工作，审批等高影响动作保留人工最终决定权。技术栈：Python / FastAPI / LangGraph / DeepAgents / Vue3 + TypeScript / PostgreSQL + pgvector / Docker。

**核心职责**：独立完成产品定义（PRD）、架构设计、前后端开发与测试（全栈 + 全流程）。

**关键工作**：

1. **自研轻量工作流引擎与智能审批闭环**：设计 JSON 审批链引擎（条件路由、会签/或签、代理审批、超时升级），结合 LangGraph 状态图打通"申请 → 材料预检 → 规则路由 → 人工审批（HITL）→ 通知"端到端流程；写操作统一审批门 + 业务单据号幂等键，杜绝重复创建与绕权操作。
2. **可降级、可恢复的智能体编排层**：LangGraph SuperAgent 统一调度 9 个业务智能体（审批/客服/工单/会议/文档/邮件/任务/报表/合同），基于 pgvector 的知识库 RAG 问答强制来源引用、置信度不足自动转人工；PostgreSQL Checkpointer 实现断点恢复；智能路径支持一键关闭回退纯人工流程。
3. **受限长文档多智能体分析**：在 LangGraph 主流程内接入 DeepAgents 完成长合同计划与分块读取，四节点子图实现条款证据定位与风险提示，以工具白名单 + 调用预算约束边界。

**成果（可验证）**：

- 后端完整回归 420 项测试全部通过；前端单元测试 58 项；桌面 + 移动浏览器回归 36 项，无失败/跳过用例
- 两次真实进程重启 + 13 条命令重放，无重复业务写入（Checkpointer + 幂等机制验证）
- 独立合成评测 36 样本 / 39 项测试通过；11 张界面截图逐张视觉走查；独立代码审查通过
- 功能覆盖：6 大平台模块 + 9 个智能体 + 7 类业务场景，全部写操作审计留痕

**OA 智能体管理系统**（个人独立开发）：基于 FastAPI + LangGraph + Vue3 + PostgreSQL 自研"OA 本体 + AI 智能体"一体化办公系统。独立实现 JSON 审批链工作流引擎（条件路由/会签/超时升级）、LangGraph 多智能体调度（9 个智能体：审批/客服/工单/会议/文档/邮件/任务/报表/合同）、DeepAgents 长合同受限分析；落地 HITL 人工审批门、幂等防重、断点恢复与一键降级。成果：后端 420 项回归 + 前端 58 项测试通过，两次真实重启 13 条命令重放无重复写入，功能覆盖 7 类业务场景、全操作审计留痕。

## 使用与避坑说明（重要）

1. **时间留白**：【2026.xx – 至今】按你实际开工时间填。
2. **不要写的**：
   - "性能提升 X%"——P95 ≤ 3s/5s 是 PRD 设计目标，**未做过实测压测**，写了面试会露馅；
   - "已在企业/部门上线"——目前是本地 Mock 工程验证闭环，真实企业接入是下一步（PRD V1.4 的 V2 阶段）；
   - 任何团队规模暗示——这是个人项目，写"独立开发"反而更硬气。
3. **可以主动讲的**（面试追问时的弹药）：HITL 审批门设计、幂等键 + 先对账后重试、Checkpointer 断点恢复、DeepAgents 工具白名单与预算控制——这些是有代码、有测试支撑的深度点。
4. **数字口径**：所有数字来自《p3-acceptance.md》验收记录，如后续测试数据更新，同步替换。
