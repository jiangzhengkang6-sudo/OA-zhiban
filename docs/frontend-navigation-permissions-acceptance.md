# 前端权限、导航与界面优化验收

日期：2026-10-26

## 交付范围

1. **动态权限**：菜单与路由共用访问规则，按服务端返回的权限展示功能；组织写入、会议操作等沿用权限和 `available_actions` 控制。权限变化后清理敏感草稿、重建当前页面，失去访问权时跳转至可访问页面；旧身份或旧授权下的在途响应不再应用。
2. **菜单分类**：工作台、办公业务、协同办公、智能与知识、数据报表、系统管理六组；无权限的项目及空分组隐藏。支持分组展开记忆、桌面侧栏收起、面包屑和当前项定位，保留既有详情链接与模拟工单快捷入口。
3. **界面统一**：中性浅色办公界面、统一文字层级、表格与表单间距、键盘焦点及减少动效。手机采用抽屉导航，选中菜单后关闭。会议区明确区分“开始会议”和“加入视频”，展示连接、入会、失败及关闭状态。

## 动态权限边界

- 可见页面每 30 秒检查身份；窗口重新获得焦点、恢复可见及路由访问时也检查，普通检查有 15 秒节流；遇到权限错误会主动重新获取。不是服务端即时推送，界面更新存在检查间隔。
- 菜单隐藏和路由拦截只是交互防护，接口仍必须执行后端授权。角色、部门和数据范围变化都会使当前授权视图失效。
- 手机端是响应式网页，不是独立原生 App。

## 浏览器验收

使用 `node frontend/e2e/verify-full-function-readonly.mjs`，以临时验收会话检查真实可访问页面。脚本结束撤销该会话，不修改业务记录、不调用模型、不发送邮件或企业微信通知、不加入腾讯视频房间。生成会话及关闭会话会留下认证审计记录。

- 桌面检查尺寸：1440 × 960；手机检查尺寸：390 × 844。
- 范围：当前账号可访问的 23 个桌面页面、4 个手机页面，以及侧栏偏好、账户菜单、手机导航和权限收缩/恢复。
- 智能配置、策略版本、审计中心、运维观测、降级控制未获该验收账号授权，应隐藏；不把隐藏当作这些页面的浏览器验收通过。
- 失败记录：整页逐页刷新累计触发同来源认证刷新限流，最终返回 401；已改为实际菜单的客户端导航，保留后端限流策略，不清零认证计数。
- 最终重跑 **30 项通过**：23 个桌面页面、4 个手机页面、3 项导航与动态权限交互；页面错误、失败 API 请求、被拦截的业务写入均为 0，临时会话已撤销。已目视复核桌面任务页及手机会议页截图。
- 最终回执：`output/business-acceptance-private/full-function-browser/browser-2026-10-26T04-33-09-210Z.json`；同目录保留截图及此前失败回执，属于本地私有验收材料。菜单跳转验收同时增加异步页面加载等待，避免路由地址先更新时误判内容为空。

## 剩余限制

- 本次未复测真实设备麦克风、摄像头和屏幕共享，也未验证真实多人音视频；界面状态与组件测试不等同于端到端通话验收。
- 腾讯依赖 `tcplayer.js` 的 `eval` 警告和视频 SDK 大分包（约 9.79 MB，gzip 约 3.31 MB）仍存在；SDK 按需导入，但真实弱网入会体验仍需专项验证。
- 本次是前端优化回归，不代表生产部署、全部角色、外部服务及历史功能的一次性全量验收。

## 人工复核步骤

1. 登录不同角色，确认仅出现获授权的菜单；直接输入无权限地址，应回到可访问页。
2. 保持账号登录，管理员在另一会话调整该账号权限，等待检查或重新聚焦，确认菜单、页面和操作权限同步。
3. 收起侧栏后刷新，确认偏好保留；通过业务详情链接进入，确认对应菜单高亮。
4. 在手机浏览器打开导航，选择会议管理，确认抽屉关闭且页面没有横向溢出。
5. 在允许真实通话的环境单独检查入会、设备授权、共享屏幕及结束会议，确认业务状态和音视频状态一致。
