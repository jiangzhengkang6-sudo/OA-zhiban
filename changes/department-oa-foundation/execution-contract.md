日期：2026-10-18。状态：已批准。用户在本契约呈现后回复“确认”，批准 M1 B1–B5 串行实施及项目内人工执行计划/审查记录替代缺失工具。本文不是既有 P1 执行契约的延续批准。

## Intent Lock

按照本目录 proposal/specs/design/tasks，建立真实本地账号、组织、会话和权限底座，保持旧业务兼容，为 M2 人工 OA 流程提供可信身份。先完成 M1，不将已有智能体演示误报为正式 OA。

## Approved Behavior

用户已批准：M1-01 非破坏迁移；M1-02 初始化与登录；M1-03 可撤销令牌及轮换；M1-04 权威身份动态复核；M1-05 组织/RBAC/范围；M1-06 生命周期与审计；M1-07 前端会话和管理；M1-08 环境隔离及兼容。全部映射到 tasks.md 的 Requirement Coverage，无未映射规格。

## Scope Fence

只修改 tasks.md File Structure 范围；新增必要路径先补文档。排除 OA 业务 Provider、流程引擎扩展、通知发件箱、报销、真实组织导入、服务器部署、Mock 历史身份自动映射和破坏性迁移。不改用户 `.env`，不改豆包主用顺序，不提交 Git 或操作共享服务器。

## Architecture And Interfaces

沿用单体架构、异步 SQLAlchemy、CurrentUser/ApiResponse；新增身份 Resolver 与 OA Provider 解耦。同步身份复核和工具授权改 async，所有调用迁移；权限变更在后续请求及提交前检查生效。Argon2id + 固定算法 JWT，refresh 只存摘要并轮换；前端 access 仅内存、refresh HttpOnly Cookie，精确 Origin 和 CSRF 校验。数据库业务和相应成功审计同事务。

## Test Obligations

- 每个规格至少一个场景，覆盖矩阵见 tasks.md；每批 Red/Green 真实运行，不拿历史测试补当前证据。
- 账号/会话并发、禁用/调岗、跨部门、附件/导出、后台与图恢复、最后管理员、审计失败回滚必须自动测试。
- 显式核对 ENVIRONMENT 和全部数据库 URL 后通过现有安全闸门，只用隔离测试库与独立目录；模型及嵌入 Mock，付费调用为零。
- B3 执行全调用搜索，不允许漏 await 或 builtin 身份回读 Mock。新身份下未能接通的旧 OA 行为明确拒绝，不伪造通过。
- 前端测试、构建和桌面/手机浏览器验证；截图不含口令、令牌或密钥。

## Review Gates

每批检查规格符合性及代码风险，记录实际通过/失败、命令和限制；高风险问题未解不得进入依赖批次。迁移、权限、会话或审计变化必须有自动化证据。B5 只可判定 M1 本地工程完成，不能宣称正式 OA 上线。
