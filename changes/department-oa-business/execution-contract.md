# M3 内置业务与智能层执行契约

日期：2026-10-19。状态：用户已明确批准，开始实施 B1。关联 [提案](proposal.md)、[规格](specs/formal-business.md)、[设计](design.md)、[任务](tasks.md)。

## Intent Lock

接续已验收的 M1/M2，完成 builtin 业务权威、报销、正式工单、站内/SMTP 通道及 AI/P2/P3 正式权限回接。保留单体架构和人工可办；不能将 Mock 数据或图状态当正式业务事实。

## Proposed Behavior

以下行为已由用户在本阶段明确批准。

1. M3-01/02：异步内置网关携带真实 actor、同一 session、trace 和服务端确认；13 个核心契约逐项映射，补工单结果对账，另测状态和字段字典两个辅助读取。无能力明确拒绝，无 Mock 兜底。
2. M3-03/04/05：受限流程引擎支持 leave/reimbursement；实例必须且仅关联一种相符业务版本。人民币整数分、两位精度、正数和上限；固定发布模板和金额分支；私有 CLEAN 发票及完整性验证；完整人工审批、重提、撤回、转交，不付款。
3. M3-06：正式工单独立表；本人确认创建/合并，分派规则固定版本，最新范围的领取/改派/办理和反馈重开。合并目标与 revision 进入幂等载荷，旧 Mock 工单不成为正式权威。
4. M3-07/08：持久化站内信、渠道任务/尝试与收件配置；SMTP 仅受理语义。有限重试明确未受理的暂时错误；未知结果保留 UNKNOWN，经有权限人员核对后显式重试。最新席位/来源权限、终态取消和扫描去重；邮件只有非敏感提示。
5. M3-09/10：命令、确认消费、结果、脱敏审计和事件同事务；图恢复按原键对账。服务端确认绑定人/线程/动作/对象及版本/载荷、10 分钟有效，模型不能生成授权。业务提交后投递失败不回滚业务。
6. M3-11/12：正式知识先范围过滤后检索、生成前复核，禁止旧 chunk 回退；策略/审计使用明确租户及业务来源，逐入口开放。文档/邮件/会议/任务/报表/合同的预览、导出、派生来源和缓存都复核权限。
7. M3-13/14：中文人工工作台及通知入口，AI 关闭仍可办；逐批与联合验证、独立预览和真实证据。任何未实现/未运行项目不得标为通过。

需求中所有 SHALL/MUST 按 [任务覆盖表](tasks.md#requirement-coverage) 绑定批次与证据；当前无未映射需求。C11 为新增契约而非声称原有实现；原盘点错误在交付时更正文档，不削减验收行为。

## Scope Fence

不含生产部署、原业务库升级、真实组织/额度导入、Mock 历史自动迁移、真实邮件外发、付费模型/嵌入调用、付款/发票真伪校验、任意表达式/BPMN、IM/公告/统一待办、M4 或 V2。不修改真实 .env、豆包主用和真实嵌入；不停止或复用旧 5182/8012、5193/8013、5194/8014 预览。

拟批准专用库仅 oa_business_m3_test、oa_business_m3_preview_test。批准后可创建、迁移和重置这两个仅测试库；不得随机新增库或重置原/M1/M2库。测试会使用本机 SMTP 捕获服务，不连接真实 SMTP。预览拟用 5195/8015，占用则选另一个空闲端口并记录。凭证/日志/附件仅存本机忽略的 data/verification/m3/。

- 按 D1-D8 和任务路径增量修改；迁移 0025/0026/0027/0028 顺序执行，旧行仅补结构辨识字段，不自动映射历史身份/业务。正式迁移破坏性 downgrade 明确拒绝。

- 新资源显式分配，不批量提升现有角色。知识绑定和正式策略/审计表与旧无权属记录隔离。

## Test Obligations

1. 迁移：空专用库、0024 含 M2 单据及余额的升级、重复升级、双主体/跨租户约束、金额/版本约束、历史内容保持；不依赖随机建额外库的旧用例。
2. 事务和竞争：单/会/或签、撤回与批准、合并/领取、同键同/异载荷、确认并发消费、进程退出重放；审计/outbox 失败全回滚；M2 额度和跨年不退化。
3. 权限：API、直接服务、工具、图恢复、后台、列表/详情/下载/导出/聚合/缓存的跨人/部门/租户、禁用、调岗和来源失权；不以隐藏菜单代替授权。
4. 通知：本机 SMTP 正常受理、未受理暂时/永久错误、受理后断连、过期租约、UNKNOWN 不自动重发、人工核对权限、队列重启、终态取消和唯一入箱。没有实际外发证据，不宣称真实 SMTP 已联通。
5. 智能层：核心 13 项+辅助 2 项正向/错误/权限/幂等/对账；意图未知转人工、伪造确认拒绝、图 checkpoint 与领域结果不一致恢复、来源撤回、外部文档不能覆盖策略。
6. 回归：M1/M2、旧显式 Mock/real 契约、P2/P3 六场景；AI 关闭人工完整闭环和模型不可用；前端全套/构建、桌面和 390px 浏览器。
7. 环境：每次数据库测试前核对三个 URL 与安全标志，只使用上述专用库；数据库套件串行，LLM/embedding=mock、本机 SMTP；不输出任何真实凭据。失败、排除、未运行和限制逐项披露。
