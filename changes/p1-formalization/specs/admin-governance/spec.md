# 配置、知识、审计与运行治理规格

## MODIFIED Requirements

### Requirement F-040：版本化策略与灰度范围

管理员 SHALL 能配置场景开关、租户/部门/用户灰度范围、超时阈值、升级规则和工具权限。系统 MUST 校验范围与阈值，采用明确的优先级规则解析冲突，保存不可覆盖的版本，并审计发布与回滚。

#### Scenario: 部门灰度覆盖全局策略

- **WHEN** 全局启用请假场景，而指定部门策略关闭该场景
- **THEN** 指定部门用户走关闭后的回退路径，其他部门仍启用
- **AND** 运行记录包含最终命中的策略版本和作用范围

#### Scenario: 非管理员修改策略

- **WHEN** 无配置权限的用户提交策略更新
- **THEN** 系统拒绝修改且原版本保持不变

#### Scenario: 回滚策略版本

- **WHEN** 管理员回滚到一个历史已发布版本
- **THEN** 系统创建新的发布版本引用该配置，不覆盖历史记录
- **AND** 后续任务使用新发布版本，在途任务按其策略快照继续或显式迁移

### Requirement F-041：知识来源与版本治理

知识运营人员 SHALL 能上传 Markdown、HTML 和 PDF 文件，预览解析结果，并维护来源、版本、生效/失效时间、权限标签和责任人。同一来源发布新版本时 MUST 保留历史版本；过期、下线或未生效版本不得参与检索。

#### Scenario: 发布 PDF 新版本

- **WHEN** 知识运营人员上传同一来源的新版 PDF、检查解析预览并发布
- **THEN** 系统创建递增版本，保存文件哈希、页码定位和责任人
- **AND** 新查询仅检索当前有效发布版本

#### Scenario: 定时失效

- **WHEN** 当前时间达到文档失效时间
- **THEN** 文档无需人工操作即不再参与检索
- **AND** 历史审计仍能识别曾使用的具体版本

#### Scenario: 解析失败

- **WHEN** 上传文件无法解析或为空
- **THEN** 系统拒绝发布并展示可定位的解析错误
- **AND** 不生成可检索切片

### Requirement F-042：受控审计检索与导出

审计人员 SHALL 能按用户、业务单据号、会话 ID、trace_id、时间和动作组合查询。导出 MUST 应用与页面一致的权限、筛选和脱敏规则，并记录导出人、条件、文件摘要和结果。

#### Scenario: 组合检索审批轨迹

- **WHEN** 审计人员按业务单据号和时间范围查询
- **THEN** 系统按时间返回路由、工具、预检、人工决定、业务写入和通知事件

#### Scenario: 导出审计报告

- **WHEN** 有导出权限的审计人员导出当前筛选结果
- **THEN** 系统生成受控文件且敏感字段按策略脱敏
- **AND** 导出动作本身进入不可修改的审计记录

#### Scenario: 无导出权限

- **WHEN** 仅有查询权限的用户请求导出
- **THEN** 系统拒绝导出且不生成文件

### Requirement F-043：可定位运行观测

运维人员 SHALL 能查看按场景和时间聚合的节点耗时、工具错误、模型请求/token 用量、转人工率和任务结果。每个聚合指标 MUST 能下钻到授权范围内的运行 trace、节点和工具调用。

#### Scenario: 从工具错误下钻

- **WHEN** 运维人员打开某时间段的工具错误指标并选择一个错误类型
- **THEN** 页面列出对应 trace、节点、工具、耗时和脱敏错误摘要
- **AND** 可跳转到同一 trace 的完整运行轨迹

#### Scenario: 模型用量缺失

- **WHEN** 模型供应商未返回 token 统计
- **THEN** 指标将该次调用标记为统计缺失而不是记为零

### Requirement F-044：可控降级与回退

管理员 MUST 能按场景、部门或租户一键关闭智能路径。关闭后，新任务 SHALL 使用内置确定性路径或外部 OA 原路径；在途任务不得丢失，并须按策略继续、暂停或转人工。

#### Scenario: 关闭请假智能路径

- **WHEN** 管理员关闭指定租户的请假智能路径
- **THEN** 新请假请求收到明确回退入口且不再调用模型或智能子图
- **AND** 已创建业务单据仍可通过权威审批路径处理

#### Scenario: 恢复智能路径

- **WHEN** 健康检查恢复且管理员重新启用场景
- **THEN** 后续新任务使用新生效策略
- **AND** 暂停任务仅在显式重试后恢复，不被批量自动重放
